# Arthurian — Site institucional

Primeira versão funcional do site da Arthurian — Corretora de Seguros e Consultoria Empresarial.

## Arquivos
- `index.html`: página inicial
- `styles.css`: identidade visual e responsividade
- `script.js`: menu, animações e interação “Mito ou Verdade”
- `politica-de-privacidade.html`: estrutura provisória
- `assets/logo-arthurian.png`: logomarca tratada para o site

## Antes da publicação definitiva
- Inserir CNPJ, razão social, endereço e registro SUSEP.
- Confirmar e-mail e redes sociais oficiais.
- Substituir depoimentos provisórios por depoimentos reais autorizados.
- Substituir nomes provisórios das seguradoras pelos logotipos oficiais autorizados.
- Revisar a Política de Privacidade.
